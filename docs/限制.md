# 研究限制

## 1. 公平性指標並非公平性的絕對真值

本研究使用 LangFair 評估模型輸出的公平性。然而，這些指標屬於模型行為的統計代理量，不能直接等同於模型是否公平。

例如，toxicity 分數偏高不一定代表內容在實際語境中具有危害性；stereotype classifier 也可能受到反諷、否定語句或專業語境影響而誤判。Cosine similarity、BLEU 或其他文字相似度指標只能表示兩組回答的相似程度，不能單獨證明模型不存在偏見。因此，本研究將指標結果解讀為潛在偏見的偵測與群體間比較依據，而非模型公平性的絕對證明。

## 2. 評估結果受到模型與語言的影響

LangFair 的評估結果依賴 toxicity classifier、stereotype classifier、sentiment model 及 embedding model。這些模型的訓練資料、分類能力與語言涵蓋範圍都可能影響最後結果。

本系統目前的部分預設模型主要以英文資料訓練，因此在繁體中文、客服對話、專業詞彙、方言或特殊語境中的準確性不能直接假設。不同模型、threshold 或語言設定可能得到不同的公平性結果。因此，跨語言比較時必須特別注意評估模型本身所造成的偏差。

## 3. 虛擬人產生的 prompt population 未必能完全代表真實使用者

本研究使用 MatrAIx 的 persona 概念建立虛擬人，並透過虛擬人產生 prompt population。此方法可以增加使用者情境的多樣性，但虛擬人的人口分布、背景資訊與語言表達方式仍不一定等同於真實使用者。

此外，persona 的原始資料可能包含既有偏差，而生成 prompt 的語言模型也可能自行加入刻板印象或不符合真人行為的內容。若某些群體的樣本數過少，該群體的統計結果也可能不穩定。因此，虛擬人 prompt population 只能視為真實使用者的模擬，不宜直接視為真實人口的完整代表。

## 4. 反事實比較可能同時改變語意或語法

本系統的反事實方法主要透過替換 protected attribute，例如性別相關詞彙，建立成對的 prompts 或 responses。然而，詞彙替換可能造成句子不自然、文法錯誤或語意改變。

因此，兩組回答之間的差異不一定全部來自 protected attribute，也可能來自替換後的語境變化、稱謂差異或模型察覺測試痕跡。反事實結果應搭配人工檢查或語意等價性驗證，避免將所有差異都解釋為模型偏見。

## 5. 分類公平性受到資料標籤與輸出解析的限制

分類公平性指標需要 protected group、模型預測結果與真實標籤。若缺少真實標籤，系統只能計算預測結果的 representation parity，無法可靠計算 FNR、FPR、FDR 或 FOR 等錯誤率公平性指標。

此外，系統需要從模型文字輸出中解析分類結果。若模型沒有依照指定格式輸出，或輸出內容無法對應至預先定義的分類標籤，該筆資料可能被排除。即使不同群體的預測比例相近，也不代表模型的正確率與錯誤率對所有群體都公平。

## 6. 推薦公平性指標不衡量推薦品質

Jaccard、SERP 與 PRAG 等推薦公平性指標主要衡量不同 protected group 所得到的推薦清單是否相似，並不直接衡量推薦結果的正確性、實用性或個人化程度。

不同群體可能具有不同需求，因此推薦清單完全相同不一定代表公平；相反地，推薦清單不同也不必然代表存在偏見。若只追求推薦結果的一致性，可能犧牲推薦品質或使用者需求。因此，推薦公平性應與效能、相關性及使用者滿意度等指標共同分析。

## 7. 樣本數與隨機性可能影響結果穩定性

目前的指標主要回傳比例、平均值或群體間差異，但未完整處理信賴區間、顯著性檢定及不同 random seed 所造成的變異。

LLM 的輸出具有隨機性，而 prompt population 的抽樣方式、樣本數與群體比例也會影響結果。當兩組指標差異很小，不能僅根據單次實驗結果判斷兩群體確實存在公平性差異。後續研究應透過重複實驗、增加樣本數及報告信賴區間，以確認結果的穩定性。

## 8. 尚未完整衡量公平性與效能之間的取捨

本研究主要關注 toxicity、stereotype、counterfactual、classification 與 recommendation fairness，尚未完整分析公平性改善是否會影響模型的任務效能、回答品質、準確率、推薦相關性或使用者體驗。

因此，公平性指標較低或群體差異較小，不代表整體系統一定較好。實際應用時，仍需同時考慮公平性、正確性、效能與任務目標。

## 總結

本研究的公平性評估結果會受到 prompt population 分布、虛擬人生成方式、語言特性、評估模型準確度、threshold 設定、輸出解析方式及樣本數影響。因此，研究結果應被視為模型潛在偏見的初步偵測與群體比較，而不應被解讀為模型公平性的絕對證明。
